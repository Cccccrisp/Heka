# Heka Brand System v0.1

## The mark

- **Wordmark:** `HEKΛ` — the `Λ` is the A and signals an open, evolving form.
- **Product mark:** an `H` with a gold angled path. It is the small-size version of the same visual language, not a second logo.
- **Meaning:** the gold angled line is a Trace entering the system: an event is recorded, reviewed, then becomes part of an evolving model.

## Use

| Situation | Asset |
| --- | --- |
| Product sidebar, README header, web navigation | `web/assets/heka-wordmark.svg` |
| App icon, small avatar, favicon | `web/assets/heka-mark.svg` |
| Campaign / launch visual | The original full lockup may include the tagline. |

The tagline `UNDERSTAND YOURSELF. EVOLVE YOURSELF.` is a campaign lockup, not a persistent UI element.

## Tokens

| Token | Value | Role |
| --- | --- | --- |
| Ink | `#202223` | Primary text and dark surfaces |
| Gold | `#B78A43` | Trace, active state, and accent |
| Paper | `#F8F7F4` | Product background |
| Signal red | `#D9514E` | Calendar activity dot only |

Use flat gold in product UI. Metallic gradients belong only in editorial or launch material, where small-size reproduction is not required.
