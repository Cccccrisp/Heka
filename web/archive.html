CLOUD / ONLY ON EXPLICIT REQUEST

云端综合模型

用于你主动发起的深入判断、问题综合和行动方案。不会自动读取数据库。

DATA BOUNDARY / WHAT MOVES

资料不会自动离开你的设备。

只有你主动使用云端功能时，Heka 才会发送对应的一小份资料包。

本地 Trace 记录与初步判断发送：无

原始记录、追问、结构化 Trace 和本地数据库都只在你的电脑与 Ollama 之间处理。

“云端深入判断”发送：当前这一条对话

只发送你按下按钮时这条 Trace 的对话文本；不会带走整个数据库或当前模型。

“问 Heka 一个问题”发送：问题 + 当前确认模型 + 最近最多 12 条证据

证据包可能包含原记录、结构化 Trace 和候选状态，用来让云端回答有依据。它不会自动保存为模型更新。

“生成行动方案”发送：你确认的问题 + 最近最多 12 条证据

用于提出三个可检验的选项；云端不能写数据库、不能执行行动。

LOCAL ARCHIVE / CAN BE TAKEN WITH YOU

你的本地 SQLite 包含：原始记录、Obsidian 来源、结构化 Trace、候选与审阅状态、初始自述、确认后的模型快照，以及行动复盘。API Key 不属于档案，也不应导出或分享。
